# UX Designer Collaboration Patterns

## With Frontend Developer

### Design Handoff Flow
```
UX Designer creates mockups in Figma
  → Exports design specs (spacing, colors, typography)
  → Frontend Dev implements UI
  → UX Designer reviews implementation
  → Provides feedback on visual accuracy
  → Frontend Dev iterates
  → Final design QA
```

### Key Interactions
- Share Figma links with dev mode access
- Document responsive breakpoints
- Specify animation timing and easing
- Review PRs for design accuracy
- Pair on complex interactions

## With Product Owner

### Feature Design Flow
```
Product Owner defines requirements
  → UX Designer researches user needs
  → Proposes design solutions
  → Product Owner reviews and approves
  → UX Designer iterates based on feedback
  → Final design approval
```

### Key Interactions
- Clarify feature requirements
- Present design options with tradeoffs
- Advocate for user needs
- Negotiate scope based on constraints

## With QA Lead

### Quality Assurance Flow
```
UX Designer defines usability criteria
  → QA Lead creates acceptance tests
  → QA tests against criteria
  → Reports UI/UX bugs
  → UX Designer provides fixes
  → Accessibility testing coordination
```

### Key Interactions
- Define acceptance criteria for UX
- Review QA findings for UX issues
- Coordinate accessibility audits
- Prioritize UX bugs

## With Data Analyst

### Data-Informed Design Flow
```
Data Analyst provides usage metrics
  → UX Designer interprets behavior patterns
  → Requests additional instrumentation
  → Data Analyst tracks new events
  → Joint A/B test analysis
  → Data informs design iterations
```

### Key Interactions
- Request analytics for design decisions
- Design A/B test variants
- Interpret funnel data
- Measure design impact

## With Stakeholder Representative

### Stakeholder Communication Flow
```
Stakeholder Rep gathers feedback
  → UX Designer translates to improvements
  → Conducts user research
  → Stakeholder Rep validates with users
  → Joint presentation to stakeholders
```

### Key Interactions
- Understand stakeholder concerns
- Present design rationale
- Coordinate user acceptance testing
- Communicate design changes

## Communication Protocols

| Type | When to Use | Blocking? |
|------|-------------|-----------|
| Consultation | UX questions, best practices | No |
| Review | Implementation review, design additions | No |
| Escalation | Scope conflicts, resource needs | Depends |

## Escalation Paths

- **Product Owner** - Feature scope, priority conflicts
- **Frontend Developer** - Implementation feasibility
- **Tech Lead** - Resource conflicts, tooling needs
