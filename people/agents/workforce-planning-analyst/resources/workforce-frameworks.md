# Workforce Planning Frameworks

## Planning Cycle

| Quarter | Activity |
|---------|----------|
| Q3-Q4 | Business strategy review |
| Q4 | Demand forecasting |
| Q4 | Supply analysis |
| Q4-Q1 | Workforce plan |
| All year | Monitor and adjust |

## Forecasting Methods

### Top-Down
- Start with business goals
- Apply ratios to estimate headcount
- Example: $100M / $250k per emp = 400 headcount

### Bottom-Up
- Managers estimate needs
- Aggregate across teams
- Risk: Over-asking

### Hybrid (Recommended)
- Top-down sets constraints
- Bottom-up validates feasibility
- Negotiate priorities

## Workforce Ratios

| Function | Ratio |
|----------|-------|
| Revenue/employee | $150-300k (SaaS) |
| CSM | 1 per $500k-2M ARR |
| Support | 1 per 100-500 tickets |
| HR | 1 per 50-100 employees |
| Span of control | 5-10 direct reports |

## Labor Cost Components

| Component | Example ($150k base) |
|-----------|---------------------|
| Base | $150k |
| Bonus | $20k |
| Equity (annual) | $25k |
| Benefits | $40k |
| Payroll taxes | $15k |
| Recruiting | $20k |
| **Total** | **~$270k** |

## Scenario Modeling

**Growth Scenarios**:
- Aggressive: 2x revenue
- Steady: 30% YoY
- Flat: Miss targets

**Budget Constraints**:
- Labor cap: 60% of revenue
- Hiring budget: $X for N hires
- Reduction: 10% efficiency

**Attrition**:
- High (20%): More backfills
- Low (10%): Fewer hires needed
