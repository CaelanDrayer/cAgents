# Onboarding Frameworks

## Pre-Boarding Checklist

### Paperwork
- [ ] I-9 (employment eligibility)
- [ ] W-4 (tax withholding)
- [ ] Direct deposit
- [ ] Emergency contacts
- [ ] Benefits enrollment
- [ ] Equity agreements
- [ ] Confidentiality agreement
- [ ] Background check

### Equipment
- [ ] Laptop (Mac/PC)
- [ ] Monitor, keyboard, mouse
- [ ] Headset
- [ ] Office supplies/stipend

### Access
- [ ] Email account
- [ ] Slack/Teams
- [ ] HRIS account
- [ ] Role-specific tools
- [ ] Building badge
- [ ] VPN setup

### Communication
- [ ] Welcome email sent
- [ ] First-week agenda shared
- [ ] Org chart provided
- [ ] Buddy assigned
- [ ] Manager intro scheduled

## Day 1 Agenda

| Time | Activity |
|------|----------|
| 9:00 | Welcome and greeting |
| 9:30 | IT setup support |
| 10:30 | HR orientation |
| 12:00 | Lunch with buddy |
| 1:00 | Meet manager and team |
| 2:00 | First assignment |
| 4:00 | Office tour / workspace setup |

## Program Components

### HR Orientation (2-3 hours)
- Company history, mission, values
- Org structure and leadership
- Benefits overview
- Policies and code of conduct
- Systems training

### Department Onboarding (1-2 weeks)
- Team structure and roles
- Department goals
- Key projects
- Tools and workflows
- Cross-functional intros

### Role-Specific Training (2-4 weeks)
- Technical skills
- Product deep-dive
- Customer personas
- First real project
- Shadowing

## Check-in Questions

### 30 Days
- How is training going?
- Do you have what you need?
- How is team integration?
- Any surprises?

### 60 Days
- How is your workload?
- Clear on expectations?
- Career development interests?
- Broader connections?

### 90 Days
- How do you feel about performance?
- Are you happy here?
- What could improve?
- Goals for next quarter?
