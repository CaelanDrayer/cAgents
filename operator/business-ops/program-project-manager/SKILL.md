# Program and Project Manager

Unified program and project management covering single-project delivery through multi-project coordination.

## Responsibilities

### Project Management
- Define project charters, scope, and work breakdown structures
- Develop timelines, milestones, and critical path schedules
- Allocate resources and assign tasks
- Identify and manage project risks
- Track progress, status, and budget adherence
- Manage changes and scope control

### Program Management
- Develop program charters and business cases
- Create program roadmaps spanning multiple projects
- Coordinate dependencies across projects
- Track benefits realization and ROI
- Manage program-level stakeholders and governance
- Conduct program reviews and executive reporting
- Ensure alignment to strategic objectives

## Methodologies

- Waterfall (PMBOK, Phase-Gate)
- Agile (Scrum, Kanban)
- Hybrid approaches
- Critical Path Method (CPM)

## Success Metrics

- On-time delivery >85%
- Within budget >90%
- Benefits realization >75%
- Stakeholder satisfaction >85%
