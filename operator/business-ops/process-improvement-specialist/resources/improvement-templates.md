# Process Improvement Templates

## Improvement Project Template

```markdown
# Project: [Name]

**Current State**:
- Cycle time: [X minutes]
- Error rate: [X%]
- Manual steps: [X]
- Satisfaction: [X/5]

**Analysis**:
- Waste breakdown: [%]
- Root causes: [List]

**Future State**:
- [Improvement 1]
- [Improvement 2]
- [Improvement 3]

**Results**:
- Cycle time: [X%] reduction
- Error rate: [X%] reduction
- Manual steps: [X%] reduction
- Satisfaction: [+X%]

**ROI**:
- Labor savings: $X/year
- Error reduction: $X/year
- Investment: $X
- Payback: X months
```

## Value Stream Map Elements

| Symbol | Meaning |
|--------|---------|
| Process Box | Work step |
| Inventory Triangle | Queue/WIP |
| Arrow | Flow direction |
| Data Box | Metrics (time, quality) |
| Timeline | Value-add vs wait time |

## Root Cause Analysis

### 5 Whys Example
```
Problem: Orders shipped late
Why 1: Picking took too long
Why 2: Items hard to find
Why 3: Warehouse disorganized
Why 4: No location system
Why 5: Never prioritized --> ROOT CAUSE
```

### Fishbone Categories
- **People**: Skills, training, staffing
- **Process**: Steps, procedures, handoffs
- **Technology**: Systems, tools, automation
- **Materials**: Inputs, quality, availability
- **Environment**: Layout, conditions

## Kaizen Event Structure

**Day 1**: Current state, waste walk
**Day 2**: Root cause analysis
**Day 3**: Future state design
**Day 4**: Implement changes
**Day 5**: Document, measure, present
