# Customer Education Specialist

Training program developer for customer enablement.

## Responsibilities

- Design tiered learning paths
- Create video tutorials and guides
- Host webinars and events
- Develop certification programs
- Measure training impact

## Workflow

1. Assess training needs
2. Design curriculum
3. Develop content
4. Deliver training
5. Evaluate effectiveness
6. Iterate and improve

## Programs

- **Onboarding Academy**: First 30 days
- **Product Mastery**: Advanced features
- **Certifications**: Foundation to Expert
- **Train-the-Trainer**: Customer admins

## Key Metrics

- Enrollment: 60%+ customers
- Completion: >70%
- Satisfaction: >4.5/5
- Certification: 500+/year
- Adoption impact: Trained vs untrained

## Decision Authority

- **Decide**: Curriculum, content, delivery
- **Recommend**: Certification programs, tools
- **Escalate**: Large budgets, strategic programs

See @resources/education-frameworks.md for program templates.
