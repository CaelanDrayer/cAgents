# Sales Engineer Templates

## Technical Discovery Checklist

### Current State
- [ ] Current solution/process
- [ ] Pain points and limitations
- [ ] Existing tech stack
- [ ] Integration requirements
- [ ] Data migration needs

### Requirements
- [ ] Must-have features
- [ ] Nice-to-have features
- [ ] Performance requirements
- [ ] Security/compliance needs
- [ ] Timeline and constraints

### Stakeholders
- [ ] Technical decision maker
- [ ] Business decision maker
- [ ] End users
- [ ] IT/Security team

## Demo Best Practices

### Before Demo
- Confirm attendees and roles
- Understand use cases
- Prepare tailored scenarios
- Test environment

### During Demo
- Start with agenda
- Lead with business value
- Show relevant features only
- Create "wow moments"
- Capture questions

### After Demo
- Summarize key points
- Address questions
- Define next steps
- Send follow-up
