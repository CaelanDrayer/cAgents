# Pricing Frameworks

## Value-Based Pricing Model

```
Customer Value = (Benefits - Costs) x Probability of Success

Price = Value Captured x Value Share (typically 10-30%)

Example:
Customer saves $500K annually
Success probability: 80%
Expected value: $400K
Price at 20% share: $80K
```

## Packaging Design

### Good-Better-Best Model

| Tier | Target | Features | Price Point |
|------|--------|----------|-------------|
| **Basic** | SMB, cost-conscious | Core features | $X/mo |
| **Pro** | Mid-market | + Advanced | $2X/mo |
| **Enterprise** | Large orgs | + Premium, SLA | Custom |

### Packaging Principles
- Clear differentiation between tiers
- Most customers should fit "Pro"
- Expansion path obvious
- No feature bloat in Basic

## Discount Analysis

### Discount Waterfall
```
List Price: $100,000
Standard Discount: -10% = $90,000
Volume Discount: -5% = $85,500
Strategic Discount: -5% = $81,225
Net Price: $81,225
Realization: 81%
```
