# Customer Marketing Templates

## Customer Lifecycle Stages

| Stage | Goal | Activities |
|-------|------|------------|
| **Onboarding** | First value | Welcome, training, setup |
| **Activation** | Key usage | Feature adoption, quick wins |
| **Engagement** | Regular use | Tips, webinars, community |
| **Expansion** | More value | Upsell, cross-sell, advocacy |
| **Advocacy** | Champions | References, testimonials, referrals |

## Onboarding Campaign

```
Day 0: Welcome email
  - Thank you for purchase
  - Getting started guide
  - Setup resources

Day 3: Training invitation
  - Onboarding webinar
  - Self-service tutorials
  - Support resources

Day 7: Check-in
  - Progress check
  - Quick wins highlight
  - Support offer

Day 14: Feature spotlight
  - Key feature introduction
  - Use case examples
  - Success tips

Day 30: Success review
  - Achievement summary
  - Next steps
  - Feedback request
```

## Customer Advocacy Program

### Tiers
- **Reference**: Case study or call
- **Champion**: Speaking, social, referrals
- **Ambassador**: Advisory board, beta, advocacy

### Incentives
- Recognition (awards, badges)
- Access (beta features, roadmap)
- Rewards (swag, credits, referral bonus)

## NPS Survey Template

```
How likely are you to recommend [Product] to a colleague?
[0-10 scale]

[If 0-6] What would need to change for you to recommend us?
[If 7-8] What can we do to improve?
[If 9-10] What do you love most about [Product]?
```
