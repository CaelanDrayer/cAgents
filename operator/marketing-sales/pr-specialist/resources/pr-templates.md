# PR Templates

## Press Release Template

```markdown
FOR IMMEDIATE RELEASE

# [Headline: Newsworthy, Benefit-Focused]

**[Subhead: Additional context]**

[CITY, DATE] -- [Company] today announced [news]. [Why it matters].

[Quote from executive about significance]

[Details paragraph 1: What, when, how]

[Details paragraph 2: Additional information]

[Quote from customer/partner if applicable]

[Boilerplate about company]

### Media Contact
[Name]
[Title]
[Email]
[Phone]

###
```

## Media Pitch Template

```markdown
Subject: [Compelling hook tied to news/trend]

Hi [Name],

[Personalized opening referencing their coverage]

[One sentence on what the story is]

[Why it's relevant to their readers now]

[What access/resources you can provide]

Would you be interested in [specific offer: interview, exclusive, data]?

[Sign off]
```

## Crisis Communication Plan

### Severity Levels
- **Level 1**: Minor - Social response needed
- **Level 2**: Moderate - PR response required
- **Level 3**: Major - Executive involvement
- **Level 4**: Critical - All-hands response

### Response Framework
1. Assess situation and severity
2. Notify appropriate stakeholders
3. Draft holding statement
4. Gather facts
5. Prepare full response
6. Monitor and update
