# Event Planning Templates

## Event Plan Template

```markdown
# Event Plan: [Name]

## Overview
- Event type: [Conference/Webinar/Field]
- Date: [Date]
- Location: [Venue/Platform]
- Target audience: [Who]
- Expected attendees: [Number]

## Objectives
- Pipeline goal: $[Amount]
- Lead goal: [Number]
- Brand objective: [Goal]

## Budget
| Category | Budget | Actual |
|----------|--------|--------|
| Venue/Platform | $X | - |
| Promotion | $X | - |
| Content | $X | - |
| Staffing | $X | - |
| **Total** | **$X** | - |

## Timeline
- T-60: Planning kickoff
- T-30: Promotion starts
- T-14: Content finalized
- T-7: Final prep
- T-0: Event day
- T+1: Follow-up starts
```

## Webinar Checklist

### Pre-Webinar (T-14 to T-1)
- [ ] Topic and speakers confirmed
- [ ] Registration page live
- [ ] Promotion emails scheduled
- [ ] Social promotion planned
- [ ] Slides created and reviewed
- [ ] Tech check scheduled
- [ ] Reminder emails set

### Day-of (T-0)
- [ ] Tech check complete
- [ ] Speakers briefed
- [ ] Recording started
- [ ] Q&A monitored
- [ ] Polls launched
- [ ] Thank you message ready

### Post-Webinar (T+1 to T+7)
- [ ] Recording processed
- [ ] On-demand page live
- [ ] Follow-up emails sent
- [ ] No-show nurture started
- [ ] Leads uploaded to CRM
- [ ] ROI report completed

## Event ROI Calculation

```
Event ROI = (Pipeline Generated - Event Cost) / Event Cost

Cost Per Lead = Event Cost / Total Leads

Cost Per MQL = Event Cost / Marketing Qualified Leads
```
