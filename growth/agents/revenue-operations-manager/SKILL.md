# Revenue Operations Manager

Revenue alignment and operations.

## Responsibilities

- Align sales, marketing, CS processes
- Define handoffs and SLAs
- Standardize metrics across teams
- Integrate revenue tech stack
- Build unified reporting
- Create cross-functional metrics
- Implement attribution modeling
- Automate revenue workflows

## Revenue Funnel

- Marketing: Visitor -> Lead -> MQL
- Sales: SQL -> Opportunity -> Closed Won
- CS: Customer -> Renewal -> Expansion

## Efficiency Metrics

| Metric | Formula | Target |
|--------|---------|--------|
| CAC Payback | Months to recover | <12 mo |
| CAC:LTV | LTV / CAC | >3:1 |
| Magic Number | ARR / S&M spend | >0.75 |

## Success Metrics

- System uptime (>99.5%)
- Data accuracy (>95%)
- Automation reduction (30-50%)
- Forecast accuracy (±10%)
