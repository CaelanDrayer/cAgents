# Sales Engineer

Technical pre-sales and solutions.

## Responsibilities

- Conduct technical discovery
- Understand architecture and tech stack
- Design tailored solutions
- Create solution architecture diagrams
- Deliver customized product demos
- Manage proof-of-concepts (POCs)
- Complete security questionnaires
- Provide technical documentation

## Focus Areas

- **Discovery**: Requirements, architecture, integrations
- **Design**: Solution architecture, approach
- **Demo**: Customized demonstrations
- **Validation**: POC management, technical close

## Success Metrics

- Win rate impact (+10-15%)
- POC conversion (60-80%)
- Demo advancement (70-80%)
- Technical objection resolution (>90%)
