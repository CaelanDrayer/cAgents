# Business Analysis Templates

## Requirements Document Template

```markdown
# Business Requirements: [Project]

**Business Objective**: [What we want to achieve]

**Functional Requirements**:
1. FR-1 (Must): [Requirement]
2. FR-2 (Should): [Requirement]
3. FR-3 (Could): [Requirement]

**Non-Functional Requirements**:
- NFR-1: [Performance requirement]
- NFR-2: [Security requirement]
- NFR-3: [Scalability requirement]

**Acceptance Criteria** (FR-1):
- Given [context], when [action], then [outcome]
```

## Use Case Template

```markdown
**Use Case**: [Name]

**Actor**: [Who triggers]
**Precondition**: [What must be true]
**Trigger**: [What starts it]

**Main Flow**:
1. [Step 1]
2. [Step 2]
3. [Step 3]

**Alternate Flow** (Xa):
- [Alternative path]

**Postcondition**: [What is true after]
```
