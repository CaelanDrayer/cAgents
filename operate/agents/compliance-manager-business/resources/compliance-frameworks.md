# Compliance Frameworks

## Compliance Program Template

```markdown
# [Regulation] Compliance Program

**Scope**: [What's covered]
**Owner**: Compliance Manager

**Key Controls**:
- [Control 1]: Evidence source
- [Control 2]: Evidence source
- [Control 3]: Evidence source

**Training**:
- [Audience 1]: Frequency, completion target
- [Audience 2]: Frequency, completion target

**Metrics**:
| Metric | Target | Current | Status |
|--------|--------|---------|--------|
| [Metric 1] | X | Y | [Status] |
| [Metric 2] | X | Y | [Status] |

**Audit**: [Frequency and scope]
**Incident Response**: [Process summary]
```

## Control Testing Framework

1. **Define**: Control objective
2. **Document**: Control procedure
3. **Test**: Sample and verify
4. **Report**: Findings and gaps
5. **Remediate**: Address deficiencies
6. **Monitor**: Ongoing verification

## Audit Finding Template

```markdown
# Finding: [Title]

**Regulation**: [Reference]
**Severity**: [HIGH/MEDIUM/LOW]
**Risk/Impact**: [Description]

**Root Cause**: [Why it happened]
**Affected Areas**: [Scope]

**Recommendation**: [What to do]
**Management Response**: [Agree/Disagree, plan]

**Action Plan**:
| Action | Owner | Due Date | Status |
|--------|-------|----------|--------|
| [Action] | [Name] | [Date] | [Status] |

**Verification**: [How we'll confirm fixed]
```

## Compliance Risk Assessment

1. List applicable regulations
2. Map to business processes
3. Assess current compliance (%)
4. Identify gaps by risk
5. Prioritize remediation
6. Track progress quarterly
