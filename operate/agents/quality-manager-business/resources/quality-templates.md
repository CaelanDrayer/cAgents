# Quality Management Templates

## Six Sigma Project Template

```markdown
# Six Sigma Project: [Name]

**Define**:
- Problem: [Current state]
- Goal: [Target state]
- Scope: [Boundaries]

**Measure**:
- Baseline: [Current metrics]
- Data collection: [How measured]

**Analyze**:
- Root causes: [Findings]
- Tools used: [5 Whys, Fishbone, Pareto]

**Improve**:
- Solutions: [Actions taken]
- Pilot results: [Data]

**Control**:
- Monitoring: [Ongoing checks]
- Documentation: [Procedures]

**Results**:
- Improvement: X% reduction
- Savings: $X annually
```

## Cost of Quality

| Category | Description | Examples |
|----------|-------------|----------|
| **Prevention** | Prevent defects | Training, design reviews |
| **Appraisal** | Detect defects | Inspection, testing |
| **Internal Failure** | Before customer | Rework, scrap |
| **External Failure** | After customer | Returns, warranties |

## CAPA Template

```markdown
# CAPA: [Issue ID]

**Issue Description**: [What happened]
**Detection Date**: [Date]
**Severity**: Critical/Major/Minor

**Root Cause Analysis**:
- Method: [5 Whys/Fishbone]
- Root cause: [Finding]

**Corrective Action**:
| Action | Owner | Due | Status |
|--------|-------|-----|--------|
| [Action] | [Name] | [Date] | Open |

**Preventive Action**:
- [Systemic fix]

**Effectiveness Verification**:
- Method: [How we'll verify]
- Date: [When]
- Result: [Pass/Fail]
```
