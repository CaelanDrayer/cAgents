# Change Management Frameworks

## Training Delivery Guide

### Session Structure
1. **Opening** (10%): Objectives, agenda, context
2. **Content** (50%): Concepts, demonstrations
3. **Practice** (30%): Hands-on exercises
4. **Close** (10%): Summary, Q&A, next steps

### Delivery Checklist
- [ ] Materials prepared and tested
- [ ] Environment configured
- [ ] Participants confirmed
- [ ] Logistics arranged
- [ ] Recording set up (if applicable)
- [ ] Support resources ready
- [ ] Feedback collection ready

### Post-Training
- [ ] Send materials to participants
- [ ] Collect feedback
- [ ] Document questions
- [ ] Report attendance
- [ ] Schedule follow-up support

## Resistance Handling

### Common Sources
- Fear of unknown
- Loss of control
- Increased workload
- Skill concerns
- Past change failures

### Response Strategies
| Source | Response |
|--------|----------|
| Fear | Provide information, involve in planning |
| Control | Give choices where possible |
| Workload | Show time savings, phase rollout |
| Skills | Offer training, practice time |
| Past failures | Acknowledge, show what's different |

## Adoption Tracking

### Metrics
| Metric | Definition | Target |
|--------|------------|--------|
| Awareness | Know about change | 100% |
| Training | Completed training | 95% |
| Utilization | Using new system | 90% |
| Proficiency | Using correctly | 85% |

### Health Check Questions
1. Do people understand why?
2. Do they know what to do?
3. Are they equipped (skills, tools)?
4. Is support available?
5. Are leaders reinforcing?

## Reinforcement Activities

- Celebrate early wins
- Share success stories
- Recognize adopters
- Address lingering issues
- Integrate into regular processes
- Remove old ways of working
