# Common Controller Questions

These 3 questions are asked by ALL controllers at the start of coordination:

1. **Current State**: "What is the current implementation of this feature?"
2. **Constraints**: "What are the technical constraints we need to consider?"
3. **Risks**: "What are the key risks and dependencies?"

Controllers reference this via: See @shared/resources/common-questions.md

## Purpose

These questions establish baseline understanding before controller coordination:

- **Current State** prevents rework and identifies existing patterns
- **Constraints** reveals limitations and shapes solution boundaries
- **Risks** identifies blockers and establishes the critical path

## Domain Extensions

Each domain adds specialized questions on top of these universal ones. See domain-specific planner_config.yaml files for the full question catalogs.
