# Creative Process Framework

## Creative Brief Template

```markdown
# Creative Brief: [Campaign Name]

## Objective
[What we want to achieve]

## Target Audience
- Primary: [Persona, needs, motivations]
- Secondary: [Persona, needs, motivations]

## Key Message
[Single most important takeaway]

## Supporting Points
1. [Proof point 1]
2. [Proof point 2]
3. [Proof point 3]

## Tone & Style
[Adjectives describing desired feel]

## Deliverables
- [Asset 1]: Specs, quantity
- [Asset 2]: Specs, quantity

## Timeline
- Brief: [Date]
- Concepts: [Date]
- Review: [Date]
- Final: [Date]

## Mandatories
- [Brand elements, legal, disclaimers]
```

## Creative Review Checklist

### Brand Alignment
- [ ] Logo usage correct
- [ ] Colors on-brand
- [ ] Typography consistent
- [ ] Imagery style aligned

### Message Clarity
- [ ] Key message clear
- [ ] CTA compelling
- [ ] Copy on-brand voice
- [ ] Value proposition evident

### Technical Quality
- [ ] Resolution sufficient
- [ ] Formats correct
- [ ] Responsive design
- [ ] Accessibility considered
