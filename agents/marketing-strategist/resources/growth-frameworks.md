# Growth Frameworks

## AARRR Pirate Metrics

| Stage | Metric | Goal |
|-------|--------|------|
| **Acquisition** | New users, traffic sources | Volume |
| **Activation** | First value, onboarding completion | Quality |
| **Retention** | Return visits, engagement | Stickiness |
| **Revenue** | Conversion, ARPU | Monetization |
| **Referral** | Viral coefficient, shares | Amplification |

## Experiment Design Template

```markdown
# Experiment: [Name]

## Hypothesis
If we [change], then [metric] will [improve/increase] by [amount] because [reason].

## Metrics
- Primary: [Main success metric]
- Secondary: [Supporting metrics]
- Guardrail: [Metric that shouldn't decrease]

## Design
- Control: [Current state]
- Variant: [Changed state]
- Sample size: [Number needed]
- Duration: [Time to run]

## Results
- Winner: [Control/Variant]
- Lift: [%]
- Confidence: [%]
- Learning: [Key insight]
```

## Viral Loop Components

1. **Core Value**: User derives value
2. **Trigger**: Prompts user to share
3. **Channel**: Where sharing happens
4. **Incentive**: Why recipient joins
5. **Friction**: Barriers to joining
