# Enhanced Review Report Template

## Report Structure

```markdown
# Enhanced Code Review Report

**Review ID**: review_{slug}_{YYMMDD}_{NNN}
**Target**: {target_path}
**Files Reviewed**: {total} ({changed} changed, {unchanged} unchanged)
**Agents Executed**: {selected}/{total} (intelligently selected)
**Completed**: {timestamp}

## Executive Summary

### Issue Distribution
- 🚨 Critical: {count} (IMMEDIATE ACTION REQUIRED)
- ⚠️  High: {count} (Must fix before release)
- ℹ️  Medium: {count} (Should fix)
- 📝 Low: {count} (Consider fixing)

### Review Focus
- 🎯 **Security-critical files reviewed first**
- 🔍 **Diff-aware analysis** focused on changed files
- 🔁 **{count} recurring patterns detected**
- ✨ **{count} auto-fixes available** ({safe_count} safe to apply)

## 🚨 Critical Issues (IMMEDIATE ACTION)

### 1. {Issue Title}
**File**: `{file}:{line}`
**Severity**: CRITICAL
**Found by**: {agent_name}
**Priority**: 🔥 {priority_reason} (Score: {score})

**Issue**:
{description}

**Impact**:
{impact_bullets}

**Auto-Fix Available**: ✅/❌

<details>
<summary>View Auto-Fix Code</summary>

```diff
{diff_code}
```

**Additional Steps**:
{additional_steps}

</details>

**Recurring Pattern**: ⚠️/None


**Generated by Enhanced Reviewer v3.0**
```

## Severity Indicators

| Severity | Emoji | Action |
|----------|-------|--------|
| Critical | 🚨 | Immediate action required |
| High | ⚠️ | Must fix before release |
| Medium | ℹ️ | Should fix |
| Low | 📝 | Consider fixing |

## Priority Badges

| Priority | Badge | Meaning |
|----------|-------|---------|
| Security | 🔥 | Security-critical code |
| Changed | 📝 | Recently modified |
| Public | 🌐 | Public API surface |
| Complex | 🔄 | High complexity score |

## Progress Tracking During Report Generation

If `TaskCreate` and `TaskUpdate` are available, use them. If not, record progress in `workflow/coordination_log.yaml` and continue.

```
TaskCreate(subject: "[reviewer] Generate executive summary")
TaskCreate(subject: "[reviewer] Format critical issues (2 found)")
TaskCreate(subject: "[reviewer] Add auto-fix suggestions (12 available)")
TaskCreate(subject: "[reviewer] Compute review metrics")
TaskCreate(subject: "[reviewer] Write recommendations")
```
