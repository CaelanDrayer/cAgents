# Platform-Specific Development

## Console Development

### PlayStation
- GNM/GNMX graphics API
- Memory budgets (unified memory)
- Certification requirements (TRC)
- PS5 DualSense features

### Xbox
- DirectX 12 graphics
- GDK development
- XR requirements
- Smart Delivery

### Nintendo Switch
- NVN graphics API
- Portable/docked modes
- Memory constraints
- Certification (Lotcheck)

## Mobile Development

### iOS
- Metal graphics API
- Memory warnings handling
- App Store guidelines
- Thermal management

### Android
- Vulkan/OpenGL ES
- Device fragmentation
- Play Store requirements
- Background behavior

## PC Development
- Multiple GPU vendors
- Variable hardware
- Steam Deck considerations
- Ultrawide/multi-monitor

## Cross-Platform Abstraction
- Platform abstraction layer
- Input normalization
- Feature capabilities query
- Graceful degradation
