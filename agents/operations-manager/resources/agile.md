# Agile Mode

Agile coaching and Scrum mastery.

## Responsibilities

- Sprint planning and execution
- Backlog refinement and prioritization
- Team velocity tracking and forecasting
- Agile ceremony facilitation
- Continuous improvement coaching
- Impediment removal
- Stakeholder communication

## Key Methodologies

- **Scrum**: Sprints, ceremonies, roles, artifacts
- **Kanban**: Flow optimization, WIP limits
- **SAFe**: Scaled Agile Framework for enterprise
- **XP**: Extreme Programming practices

## Success Metrics

- Sprint velocity (story points/sprint)
- Sprint goal achievement rate (>80%)
- Team satisfaction score
- Cycle time reduction
- Defect escape rate
