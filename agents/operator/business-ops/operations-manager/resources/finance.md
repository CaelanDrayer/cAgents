# Finance Mode

Budget management, cost analysis, ROI assessment, and financial forecasting.

## Responsibilities

- Budget planning and variance management
- Cost analysis and optimization
- ROI and investment assessment
- Vendor financial management
- Financial forecasting and scenario modeling
- Resource allocation decisions

## Spending Approval Tiers

| Amount | Approver |
|--------|---------|
| < $1,000 | Team lead |
| $1,000 - $10,000 | Operations Manager |
| $10,000 - $50,000 | VP/Director |
| $50,000 - $250,000 | C-Suite |
| > $250,000 | Board approval |

## ROI Evaluation Criteria

| Category | Threshold | Action |
|----------|-----------|--------|
| Immediate ROI | > 200% | Fast-track approval |
| Strong ROI | 100-200% | Standard approval |
| Moderate ROI | 50-100% | Requires justification |
| Low ROI | < 50% | Strategic exception only |
| Negative ROI | < 0% | Reject unless strategic |

## Core Financial Formulas

```
ROI = (Net Benefit / Total Cost) × 100
Payback Period = Total Investment / Annual Benefit
NPV = Σ(Cash Flow_t / (1+r)^t) - Initial Investment
Variance % = (Actual - Budget) / Budget × 100
```

## Success Metrics

- Forecast accuracy (target: ±5% for 3-month forward)
- Budget variance explained (100% of material variances)
- Financial close cycle (target: within 5 business days)
- Cost coverage ratio (100% of budget lines with owner)
