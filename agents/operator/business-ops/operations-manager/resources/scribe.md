# Scribe Mode

Meeting documentation, decision capture, knowledge management, and structured summaries.

## Responsibilities

- Meeting minutes and structured summaries
- Decision documentation with rationale
- Action item tracking and follow-up
- Knowledge base management
- Technical writing and documentation
- Communication logging
- Learning and pattern extraction

## Documentation Types

- **Meeting Minutes**: Attendees → Objectives → Decisions → Action Items → Next Steps
- **Decision Log**: DACI format (Driver, Approver, Contributor, Informed)
- **Action Item Log**: Owner, deadline, source meeting, status
- **Knowledge Base Article**: Summary, Details, Examples, Related
- **Executive Summary**: Pyramid Principle — conclusion first, then supporting evidence
- **ADR**: Architecture Decision Record — context, decision, status, consequences

## Key Standards

- Distribute meeting notes within 24 hours
- Every action item: what, who, by when
- Name the decision-maker (active voice)
- Consistent naming, tagging, and filing conventions
- Confirm accuracy with participants within 24 hours

## Typical Outputs

- Meeting notes with decisions and actions
- Decision register with rationale and alternatives
- Project status reports
- Knowledge base articles
- After-Action Reviews (AAR)
