# Creative Direction Guide

Comprehensive reference for leading creative vision, establishing direction, and ensuring quality across Make domain projects.

## Creative Vision Development

### Establishing Creative Direction

Creative direction translates business objectives into a coherent aesthetic and narrative framework that guides all creative output.

**Vision Development Process**:
1. Understand the business context (goals, audience, constraints)
2. Research the competitive and cultural landscape
3. Define the creative territory (what we will and will not do)
4. Articulate the core creative idea or theme
5. Develop visual and tonal references (mood boards, tone examples)
6. Document the creative brief
7. Validate with stakeholders before execution begins

### Creative Brief Template

| Section | Description | Example |
|---------|-------------|---------|
| **Objective** | What the creative work must accomplish | Increase sign-up conversion by 20% |
| **Audience** | Who the work is for, their context and needs | Technical decision-makers, 30-50, evaluating tools |
| **Key Message** | The single most important takeaway | This tool saves engineering teams 10 hours per week |
| **Tone** | Emotional quality of the communication | Confident, approachable, technically credible |
| **Mandatories** | Non-negotiable elements | Logo placement, legal disclaimers, accessibility standards |
| **Deliverables** | What is being produced | Landing page, email sequence, social assets |
| **Timeline** | Key milestones and deadlines | Draft by Feb 10, final by Feb 20 |
| **Success Metrics** | How effectiveness will be measured | Conversion rate, engagement time, click-through |

### Mood Board Construction

Mood boards communicate creative direction visually before production begins.

**Elements to Include**:
- Color palette samples with hex values
- Typography examples showing hierarchy
- Photography or illustration style references
- Layout and composition patterns
- Texture and material references
- Competitor examples (what to avoid and what to learn from)
- Aspirational references from adjacent industries

**Organization Principles**:
- Group by theme, not by element type
- Include "yes" and "no" examples for clarity
- Annotate why each reference is included
- Present as a spectrum (conservative to bold) when direction is not yet settled

## Narrative and Content Architecture

### Story Structure for Projects

Every project tells a story. The creative director ensures narrative coherence.

**Three-Act Structure for Product Narratives**:
- **Act 1 (Setup)**: Establish the problem or opportunity the audience faces
- **Act 2 (Confrontation)**: Present the solution and demonstrate its value
- **Act 3 (Resolution)**: Show the transformed outcome and call to action

**Content Hierarchy**:
1. **Headline**: The single most compelling statement (5-10 words)
2. **Subhead**: Expands the headline with specificity (15-25 words)
3. **Body**: Delivers supporting detail and evidence
4. **Proof Points**: Data, testimonials, case studies that build credibility
5. **Call to Action**: Clear next step the audience should take

### Voice and Tone Guidelines

Voice is consistent (who we are); tone varies by context (how we adapt).

**Voice Attributes** (define 3-5 for any project):
- Each attribute has a definition and a spectrum
- Example: "Confident" means assertive without arrogance
- Example: "Clear" means simple without being simplistic
- Example: "Human" means warm without being unprofessional

**Tone Adaptation by Context**:

| Context | Tone Shift | Example |
|---------|-----------|---------|
| Error messages | Empathetic, helpful | "Something went wrong. Here is how to fix it." |
| Success states | Celebratory, brief | "You are all set." |
| Onboarding | Encouraging, clear | "Let us walk through the basics together." |
| Technical docs | Precise, neutral | "The API accepts JSON payloads up to 10MB." |
| Marketing | Aspirational, energetic | "Build what matters, faster than ever." |

## Creative Quality Review

### Review Framework

The creative director evaluates all creative output against these dimensions.

**Quality Dimensions**:

| Dimension | Question | Rating Scale |
|-----------|----------|-------------|
| **Alignment** | Does it serve the stated objective? | Off-brief / Partial / On-brief |
| **Clarity** | Is the message immediately understandable? | Confusing / Adequate / Crystal clear |
| **Consistency** | Does it match established guidelines? | Inconsistent / Mostly / Fully consistent |
| **Craft** | Is the execution polished and professional? | Rough / Competent / Exceptional |
| **Originality** | Does it stand out from generic approaches? | Generic / Distinctive / Breakthrough |
| **Audience Fit** | Will the target audience connect with it? | Mismatched / Acceptable / Resonant |

### Feedback Protocol

Effective creative feedback is specific, actionable, and respectful.

**Feedback Structure**:
1. **Acknowledge strengths** first (what is working and why)
2. **Identify the gap** between current work and the brief
3. **Provide direction** not solutions (describe the destination, let creators find the path)
4. **Prioritize** feedback items (must-fix vs. nice-to-have)
5. **Set expectations** for next review (what should be different)

**Feedback Anti-Patterns**:
- "I do not like it" (subjective, not actionable)
- "Make it pop" (vague, means different things to different people)
- "Can you try something completely different?" (without explaining why)
- Providing feedback on execution details before strategic direction is approved
- Giving contradictory feedback across review rounds

### Approval Workflow

```
Creator produces draft
    -> Self-review against brief
    -> Peer review (if applicable)
    -> Creative director review
    -> Stakeholder review (if required)
    -> Revision cycle (max 2 rounds for standard work)
    -> Final approval
    -> Production/delivery
```

**Escalation Criteria**:
- Stakeholder and creative director disagree on direction
- Revision count exceeds 2 rounds without convergence
- Timeline at risk due to review delays
- Scope change requested mid-production

## Cross-Team Coordination

### Engineering-Creative Interface

The creative director bridges engineering and creative teams within the Make domain.

**Coordination Points**:
- Design system components (ensure creative vision works within technical constraints)
- Content architecture (ensure narrative structure works with information architecture)
- Animation and interaction patterns (balance creative ambition with performance)
- Accessibility requirements (creative solutions must meet WCAG standards)
- Asset pipeline (formats, sizes, naming conventions, delivery methods)

**Handoff Checklist**:
- [ ] All assets in correct formats and resolutions
- [ ] Color values specified in design tokens (hex, RGB, HSL)
- [ ] Typography specified with fallback fonts
- [ ] Responsive behavior documented for all breakpoints
- [ ] Interaction states defined (hover, active, focus, disabled)
- [ ] Accessibility annotations included
- [ ] Content finalized and approved (no placeholder text)

## Creative Standards Maintenance

### Living Style Guide

Maintain a reference document that evolves with the project.

**Contents**:
- Brand identity elements (logo usage, color palette, typography)
- Component library (buttons, cards, forms, navigation patterns)
- Content patterns (writing style, terminology, formatting)
- Photography and illustration guidelines
- Icon and iconography standards
- Motion and animation principles
- Do and do-not examples for common scenarios

### Standards Review Cadence

- Weekly: Review new creative output for consistency
- Monthly: Audit key touchpoints against guidelines
- Quarterly: Evaluate if guidelines need updating based on new patterns
- Annually: Comprehensive standards refresh aligned with strategy
