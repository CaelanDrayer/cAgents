# Animation Types

## Locomotion
- Idle (relaxed, alert, tired)
- Walk (forward, strafe, backward)
- Run (forward, strafe, backward)
- Sprint
- Stop/start transitions
- Turn in place

## Combat
- Attack chains (light, heavy)
- Hit reactions (front, back, left, right)
- Blocks and parries
- Dodges and rolls
- Deaths (multiple variations)
- Knockdowns and getups

## Interactions
- Pick up item
- Open door/chest
- Use lever/button
- Climb ladder
- Sit/stand

## Special
- Emotes and gestures
- Victory/defeat poses
- Abilities and spells
- Mounting/dismounting

## Animation Guidelines
- **Anticipation**: Wind-up before action
- **Follow-through**: Momentum after action
- **Weight**: Heavier = slower, more force
- **Responsiveness**: Player input feels immediate
- **Blending**: Smooth transitions between states

## Timing Reference
- Attack start: 0.1-0.3s
- Recovery: 0.2-0.5s
- Dodge: 0.3-0.5s
- Turn in place: 0.2-0.4s
