# Concept Art Design Process

## Ideation Phase
1. Gather references and mood boards
2. Thumbnail sketches (many small options)
3. Silhouette exploration
4. Color studies

## Development Phase
1. Select strongest thumbnails
2. Develop into refined sketches
3. Add detail and definition
4. Explore variations

## Finalization Phase
1. Final illustration/painting
2. Turnaround sheets if needed
3. Call-outs for details
4. Handoff documentation

## Character Design Checklist
- [ ] Distinct silhouette
- [ ] Readable at game camera distance
- [ ] Consistent with art style
- [ ] Functional for gameplay
- [ ] Personality visible in design
- [ ] Color palette defined

## Environment Design Checklist
- [ ] Mood and atmosphere established
- [ ] Scale reference included
- [ ] Lighting direction indicated
- [ ] Key landmarks identified
- [ ] Material palette defined
