# Plot Development Patterns

## Twist Types
- **Revelation**: Hidden truth exposed
- **Reversal**: Ally becomes enemy (or vice versa)
- **Misdirection**: Red herring pays off
- **Escalation**: Stakes suddenly higher
- **Consequence**: Past action catches up

## Good Twist Criteria
- Surprising but logical
- Foreshadowed (on reread)
- Changes meaning of prior events
- Raises stakes
- Character-driven

## Complication Patterns
- **Obstacle**: Blocks path to goal
- **Dilemma**: Two bad choices
- **Deadline**: Time pressure added
- **Sacrifice**: Must give up something
- **Betrayal**: Trust broken

## Subplot Integration
- Mirror main theme
- Provide contrast
- Develop secondary characters
- Add texture to world
- Converge at climax

## Causality Chain
```
Event A causes Event B
Event B causes Event C
C leads to consequence D
D forces character choice
Choice leads to climax
```

## Tension Escalation
1. Introduce problem
2. First attempt fails
3. Stakes increase
4. Second attempt worse
5. All seems lost
6. Final confrontation
