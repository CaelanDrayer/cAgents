# Editing Guide

## Common Fixes

| Issue | Solution |
|-------|----------|
| Plot hole | Add scene or explanation |
| Slow pacing | Cut redundant scenes |
| Rushed pacing | Expand key moments |
| Voice drift | Rewrite for authentic voice |
| Unclear motivation | Add internal thought |
| Confusing passage | Rewrite for clarity |
| Purple prose | Simplify, cut adjectives |
| Telling not showing | Convert to scene |
| Weak verbs | Replace with stronger |

## Structural Checklist
- [ ] Plot coherent with no holes
- [ ] Character arcs complete
- [ ] Pacing balanced
- [ ] Theme resonates
- [ ] Stakes clear
- [ ] Ending satisfying

## Prose Checklist
- [ ] Clarity throughout
- [ ] Voice consistent
- [ ] Show vs tell balanced
- [ ] Description vivid but not overdone
- [ ] Dialogue natural

## Final Pass
- [ ] Opening hooks reader
- [ ] No loose threads
- [ ] Consistent world details
- [ ] No redundant scenes
- [ ] Strong ending impact
