# Prose Techniques

## Show vs Tell
- **Action scenes**: Heavy show (vivid, immediate)
- **Introspection**: Balanced (efficient telling OK)
- **Description**: Show through sensory detail
- **Exposition**: Minimal tell, naturally integrated

## Pacing Control
- Short sentences: Fast pacing, action, tension
- Long sentences: Slow pacing, description
- Paragraph breaks: Breathing room
- Chapter breaks: Major transitions

## Description Strategy
- Sensory details: All five senses
- Specific over generic: "oak table" not "table"
- Integrated with action
- POV-filtered: Through character's lens

## Opening Hooks
- Start in motion
- Raise a question
- Establish voice
- Create intrigue
- Ground in setting

## Scene Structure
1. Goal: What character wants
2. Conflict: Obstacle to goal
3. Disaster/Decision: Outcome and choice
4. Transition: Bridge to next scene

## Sentence Variety
- Vary length
- Vary structure
- Vary openings
- Create rhythm
