# Game Writing Guidelines

## Dialogue Best Practices
- Keep lines short (easier for VO, reading)
- Each character has distinct voice
- Avoid exposition dumps
- Show, don't tell when possible
- Consider skip/speed options

## Character Voice Checklist
- Vocabulary level
- Speech patterns and rhythm
- Cultural/regional influences
- Personality traits in word choice
- Consistent mannerisms

## Barks and Callouts
- Short (1-5 words ideal)
- Informative for gameplay
- Multiple variations
- Context-appropriate
- Not annoying on repeat

## Lore Writing
- Reward curious players
- Don't require for understanding
- Multiple perspectives add depth
- Leave some mystery
- Integrate with world visually

## UI/System Text
- Clear action verbs
- Consistent terminology
- Avoid jargon unless in-world
- Test at actual font sizes
- Consider localization length

## Localization Tips
- Avoid idioms that don't translate
- Leave space for text expansion
- No text baked into images
- Separate gender/number variations
- Provide context for translators
