# Story Structure Patterns

## Three-Act Structure
- **Act 1**: Setup (25%)
- **Act 2**: Confrontation (50%)
- **Act 3**: Resolution (25%)

## Hero's Journey
1. Ordinary World
2. Call to Adventure
3. Refusal of Call
4. Meeting Mentor
5. Crossing Threshold
6. Tests, Allies, Enemies
7. Approach to Innermost Cave
8. Ordeal
9. Reward
10. Road Back
11. Resurrection
12. Return with Elixir

## Tension Curve
```
       /\
      /  \  Climax
     /    \
    /      \____
   /            \
__/              \__
Setup  Build  Resolution
```

## Transition Techniques
- Scene break (time skip)
- POV shift
- Location change
- Flashback/forward
- Parallel cut

## Pacing Guidelines
- Vary scene length
- Action followed by reflection
- Build tension gradually
- Release tension meaningfully
- End chapters with hooks
