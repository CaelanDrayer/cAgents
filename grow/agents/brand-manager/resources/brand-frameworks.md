# Brand Frameworks

## Brand Positioning Statement

```
For [target audience]
Who [need/want]
[Brand] is [category/frame of reference]
That [key benefit]
Unlike [alternatives]
[Brand] [key differentiator]
```

## Brand Voice Matrix

| Attribute | We Are | We Are Not |
|-----------|--------|------------|
| Tone | [confident] | [arrogant] |
| Language | [clear] | [jargon-filled] |
| Personality | [friendly] | [casual] |

## Brand Audit Checklist

### Visual Consistency
- [ ] Logo usage correct
- [ ] Color palette followed
- [ ] Typography consistent
- [ ] Imagery style aligned

### Voice Consistency
- [ ] Tone matches guidelines
- [ ] Language appropriate
- [ ] Messaging aligned
- [ ] Terminology consistent

## Messaging Hierarchy

1. **Brand Promise**: Core commitment to customers
2. **Value Proposition**: Primary benefit offered
3. **Supporting Messages**: Proof points and features
4. **Audience-Specific**: Tailored by persona
