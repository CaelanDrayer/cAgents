# Product Marketing Templates

## Messaging Framework

```markdown
# Messaging Framework: [Product]

## Value Proposition
[One sentence: What we do + for whom + key benefit]

## Positioning Statement
For [target audience] who [need/want],
[Product] is [category] that [key benefit].
Unlike [alternatives], [Product] [key differentiator].

## Key Messages
1. [Message 1]: [Supporting proof]
2. [Message 2]: [Supporting proof]
3. [Message 3]: [Supporting proof]

## Elevator Pitch
[30-second version]
[60-second version]

## Tagline Options
- [Option 1]
- [Option 2]
```

## Launch Plan Template

```markdown
# Launch Plan: [Product/Feature]

## Overview
- Launch date: [Date]
- Launch tier: [1/2/3]
- Objectives: [Goals]

## Pre-Launch (T-30 to T-7)
- [ ] Messaging finalized
- [ ] Sales enablement ready
- [ ] Press/analyst briefings
- [ ] Customer beta feedback

## Launch Day (T-0)
- [ ] Press release
- [ ] Blog post
- [ ] Email announcement
- [ ] Social campaign
- [ ] Website updates

## Post-Launch (T+7 to T+30)
- [ ] Demand gen campaigns
- [ ] Customer webinar
- [ ] Win/loss tracking
- [ ] Success metrics review
```
