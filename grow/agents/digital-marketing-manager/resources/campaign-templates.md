# Digital Campaign Templates

## Campaign Setup Checklist

### Google Ads
- [ ] Campaign objective selected
- [ ] Bidding strategy configured
- [ ] Budget set and paced
- [ ] Keywords researched and organized
- [ ] Negative keywords added
- [ ] Ad groups structured by theme
- [ ] Ad copy variations (3+ per group)
- [ ] Extensions configured
- [ ] Conversion tracking verified

### LinkedIn Ads
- [ ] Campaign objective set
- [ ] Audience targeting defined
- [ ] Company/Job title targeting
- [ ] Ad format selected
- [ ] Creative assets uploaded
- [ ] CTA configured
- [ ] Conversion tracking set

## Landing Page Optimization

### Above the Fold
- [ ] Clear headline with value prop
- [ ] Supporting subheadline
- [ ] Hero image or video
- [ ] Primary CTA visible

### Page Elements
- [ ] Benefits clearly stated
- [ ] Social proof (logos, testimonials)
- [ ] Form (minimal fields)
- [ ] Trust indicators

### Technical
- [ ] Mobile responsive
- [ ] Fast load time (<3s)
- [ ] Form works correctly
- [ ] Tracking pixels installed
