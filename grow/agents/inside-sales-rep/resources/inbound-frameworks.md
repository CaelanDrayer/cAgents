# Inbound Sales Frameworks

## Speed to Lead

| Response Time | Conversion Impact |
|---------------|-------------------|
| < 5 minutes | 100x more likely to qualify |
| 5-30 minutes | 21x more likely |
| > 30 minutes | Significant drop-off |

## Quick Qualification (BANT)

| Element | Questions | Disqualifier |
|---------|-----------|--------------|
| **Budget** | "What budget have you set aside?" | No budget, no timeline |
| **Authority** | "Who else is involved?" | Can't access decision maker |
| **Need** | "What problem are you solving?" | No clear pain |
| **Timeline** | "When do you need to solve this?" | No urgency |

## Efficient Demo Structure (30 min)

```
0-5 min: Quick discovery recap
5-10 min: Problem statement alignment
10-25 min: Solution demonstration
25-30 min: Next steps and close
```

## Trial Engagement Cadence

**Day 1**: Welcome email + getting started
**Day 3**: Check-in, offer help
**Day 7**: Feature highlight based on usage
**Day 14**: Value summary, upgrade prompt
**Day 21**: Final offer, urgency

## Trial Conversion Signals

### High Intent
- Feature usage frequency
- Team members added
- Integration connected
- Support ticket opened

### Low Intent
- No login after Day 3
- Minimal feature exploration
- No response to outreach
