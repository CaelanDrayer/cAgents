# Copy Frameworks

## AIDA Framework
- **Attention**: Hook with compelling headline
- **Interest**: Build curiosity with benefits
- **Desire**: Create emotional connection
- **Action**: Clear, compelling CTA

## PAS Framework
- **Problem**: Identify pain point
- **Agitate**: Amplify the problem
- **Solution**: Present your offer

## BAB Framework
- **Before**: Current state with problems
- **After**: Desired state achieved
- **Bridge**: How your solution gets them there

## Headline Templates

```
How to [Achieve Desired Outcome] Without [Common Obstacle]
The [Adjective] Way to [Desired Result] in [Timeframe]
[Number] [Noun] That [Promise/Benefit]
Why [Target Audience] Are [Doing Unexpected Thing]
```

## Email Subject Lines

```
Quick question about [topic]
[First name], did you see this?
The [adjective] secret to [benefit]
Last chance: [offer expires]
```

## CTA Best Practices

- Use action verbs (Get, Start, Join, Discover)
- Create urgency without being pushy
- Make benefits clear
- Test different variations
- Match CTA to funnel stage
