# Strategy Frameworks

## Strategic Plan Template

```markdown
# Strategic Plan FY[Year]-FY[Year+4]

**Vision**: [Long-term aspiration]

**Strategic Objectives**:
1. **[Objective 1]**: [Description]
   - Key Results: [Measurable outcomes]
   - Initiatives: [How we'll achieve]

2. **[Objective 2]**: [Description]
   - Key Results: [Measurable outcomes]
   - Initiatives: [How we'll achieve]

**Resource Allocation**:
- R&D: X%
- Sales/Marketing: Y%
- Operations: Z%

**Risks**: [Key risks and mitigation]

**Quarterly Milestones**: [Key checkpoints]
```

## Porter's Five Forces

| Force | Questions | Assessment |
|-------|-----------|------------|
| **Rivalry** | How intense is competition? | High/Medium/Low |
| **Supplier Power** | Can suppliers dictate terms? | High/Medium/Low |
| **Buyer Power** | Can customers dictate terms? | High/Medium/Low |
| **Substitutes** | Easy to switch to alternatives? | High/Medium/Low |
| **New Entrants** | Easy for newcomers to enter? | High/Medium/Low |

## Ansoff Matrix

|            | Existing Products | New Products |

| **Existing Markets** | Market Penetration | Product Development |
