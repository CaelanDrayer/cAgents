# Contract Review Frameworks

## Key Clauses Analysis

### Parties and Scope
- Who, what services/products
- Scope and exclusions

### Term and Termination
- Initial term, renewals
- Termination rights (cause, convenience)
- Notice requirements

### Pricing and Payment
- Fees, schedule, late payment
- Expense reimbursement
- Price adjustments

### Intellectual Property
- Ownership of work product
- License grants and restrictions
- IP indemnification

### Data Protection
- Processing obligations
- Security requirements
- Breach notification
- GDPR/CCPA compliance

### Liability
- Caps and exclusions
- Indemnification scope
- Insurance, warranties

## High-Risk Terms (Escalate)

- Unlimited liability
- Broad indemnification
- No termination rights
- Unclear IP ownership
- Inadequate data protection
- Auto-renewal without notice

## Redlining Best Practices

- Track changes (add/delete visible)
- Comment with rationale
- Mark priority (Critical/Important/Preferred)
- Propose alternatives

## Review Package Template

```markdown
# Contract Review Summary

## Overview
- Type, Counterparty, Value

## Executive Summary
- Critical Issues (must resolve)
- Important Issues (negotiate)
- Preferred Changes (nice-to-have)

## Risk Matrix
| Risk | Severity | Likelihood | Mitigation |

## Negotiation Strategy
- Round 1: Critical
- Round 2: Important
- Round 3: Preferred
- Fallback positions
```

## Contract Types

**Customer**: MSA, SaaS, SOW, ToS
**Vendor**: Service, software, NDAs
**Partnership**: Strategic, reseller, JV
