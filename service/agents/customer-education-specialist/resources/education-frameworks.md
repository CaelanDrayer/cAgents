# Customer Education Frameworks

## Onboarding Academy

### Module 1: Getting Started (30 min)
- Product overview
- Account setup
- First project
- Invite team
- Target: >90% completion

### Module 2: Core Features (60 min)
- Feature walkthroughs
- Best practices
- Basic workflows
- Target: >80% completion

### Module 3: Integrations (45 min)
- Common integrations
- API basics
- Troubleshooting
- Target: >70% completion

### Weekly Webinar (60 min)
- Demo, use cases, tips, Q&A
- Target: 50+ attendees

## Certification Levels

| Level | Content | Passing |
|-------|---------|---------|
| Foundation | Core features | 80% |
| Professional | Advanced + labs | 85% |
| Expert | Architecture + capstone | 90% |
| Administrator | Config + security | 85% |

## Video Production Process

1. **Plan**: Objective, script, demo prep
2. **Record**: <10 min, face intro/outro
3. **Edit**: Branding, captions
4. **Publish**: LMS, promote

## Webinar Structure (60 min)

- Welcome (5 min)
- Presentation/demo (35 min)
- Q&A (15 min)
- Wrap-up and resources (5 min)

## Interactive Lab Structure

