## Lean 8 Wastes (DOWNTIME)

| Waste | Description | Example |
|-------|-------------|---------|
| **D**efects | Errors, rework | Wrong orders |
| **O**verproduction | Too much | Excess inventory |
| **W**aiting | Idle time | Approval delays |
| **N**on-utilized talent | Underused skills | Manual work for experts |
| **T**ransportation | Movement of materials | Multiple handoffs |
| **I**nventory | Excess stock | WIP buildup |
| **M**otion | Human movement | Searching for items |
| **E**xtra processing | More than needed | Redundant checks |

## Process Improvement ROI

```
Savings Calculation:
- Labor reduction: X FTEs x $Y salary = $Z
- Error reduction: X errors x $Y cost = $Z
- Efficiency gain: X hours x $Y rate = $Z
Total Annual Savings: $[Sum]

Investment: $[Amount]
Payback: Investment / Annual Savings
NPV (3 yr): Savings x 2.5 - Investment
```

## Capacity Planning

| Metric | Formula |
|--------|---------|
| Theoretical | Max output in ideal conditions |
| Effective | Realistic sustainable output |
| Actual | Current output |
| Utilization | Actual / Effective x 100 |
| Bottleneck | Constraint limiting throughput |
