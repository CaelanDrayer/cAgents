# Scenario Planning Framework

## Process
1. Identify focal question
2. Identify key uncertainties
3. Select two critical uncertainties
4. Create 2x2 scenario matrix
5. Develop scenario narratives
6. Identify implications
7. Stress-test strategies
8. Develop contingencies

## Scenario Matrix Example

## Scenario Components
- Name and narrative
- Key drivers
- Implications for strategy
- Early warning signals
- Contingency actions

## Common Pitfalls
- Too many scenarios
- Not different enough
- No clear implications
- No monitoring plan
