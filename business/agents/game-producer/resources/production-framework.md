# Production Framework

## Milestone Planning
1. Define milestone goals
2. Break into team deliverables
3. Identify dependencies
4. Estimate effort
5. Allocate resources
6. Set review gates

## Sprint Process
- Sprint planning (start)
- Daily standups
- Blockers escalation
- Sprint review (end)
- Retrospective

## Tracking Artifacts
- Project schedule (Gantt/roadmap)
- Sprint backlog
- Risk register
- Status dashboard
- Meeting notes

## Status Report Template
```
Milestone: {name}
Status: {Green/Yellow/Red}
Progress: {X}% complete

Completed This Week:
- {item 1}
- {item 2}

Next Week Focus:
- {item 1}
- {item 2}

Blockers/Risks:
- {blocker 1}: {mitigation}
```

## Risk Escalation
- **Green**: On track, minor issues
- **Yellow**: At risk, needs attention
- **Red**: Critical, executive escalation
