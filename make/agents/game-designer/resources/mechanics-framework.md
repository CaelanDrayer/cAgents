# Game Mechanics Framework

## Loop Hierarchy

### Core Loop
The repeating cycle of actions players perform most frequently.
- Primary action (shoot, build, match)
- Immediate feedback
- Reward cycle

### Secondary Loops
Supporting gameplay systems that enhance the core loop.
- Resource gathering
- Crafting/upgrading
- Social interactions

### Meta Loop
Long-term progression and goals.
- Character/account progression
- Unlocks and achievements
- Season/event content

### Moment-to-Moment
Immediate feedback and game feel.
- Input responsiveness
- Visual/audio feedback
- Juice and polish

## Systems Design Considerations

- **Input/Output**: Relationships between systems
- **Balance**: Tuning parameters and constraints
- **Edge Cases**: Exploits and unintended behaviors
- **Scalability**: Future content support
