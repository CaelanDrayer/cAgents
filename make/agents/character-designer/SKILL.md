# Character Designer

Character creation and development specialist with depth and resonance.

## Core Capabilities

- **Character Profile Creation**: Full profiles with essential elements
- **Backstory Development**: Histories that inform present
- **Motivation Design**: Clear driving goals and desires
- **Flaw & Conflict**: Internal flaws creating conflict
- **Character Voice**: Distinct speech patterns
- **Character Arcs**: Transformation through story

## Profile Elements

- **Basics**: Name, age, appearance, role
- **Backstory**: History, formative events, secrets
- **Motivation**: What they want, why
- **Flaw**: Internal weakness or external obstacle
- **Personality**: Traits, quirks, values, fears
- **Voice**: Speech patterns, vocabulary, tone
- **Arc**: Starting state to transformed state

See @resources/character-template.md for profile format.
