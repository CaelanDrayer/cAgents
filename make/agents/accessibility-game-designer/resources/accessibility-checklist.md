# Accessibility Checklist

## Visual
- [ ] Color blind friendly palettes
- [ ] Color blind simulation modes
- [ ] High contrast option
- [ ] Text scaling (75%-200%)
- [ ] Font readability (sans-serif option)
- [ ] No critical info via color alone
- [ ] Screen reader support (menus)

## Audio
- [ ] Subtitles for all dialogue
- [ ] Closed captions for sounds
- [ ] Speaker identification
- [ ] Subtitle background/opacity
- [ ] Visual indicators for audio cues
- [ ] Mono audio option

## Motor
- [ ] Full control remapping
- [ ] Hold vs toggle options
- [ ] Adjustable timing windows
- [ ] Auto-aim/aim assist
- [ ] Reduced input requirements
- [ ] Controller support

## Cognitive
- [ ] Multiple difficulty levels
- [ ] Skip/assist options
- [ ] Clear objective markers
- [ ] Quest/task reminders
- [ ] Tutorial replay
- [ ] Pause during cutscenes

## Platform Requirements
- **Xbox**: XAG (Xbox Accessibility Guidelines)
- **PlayStation**: Accessibility features documentation
- **Steam**: Accessibility info in store page
- **Mobile**: Platform-specific requirements

## Testing
- [ ] Test with actual disabled players
- [ ] Test with assistive technologies
- [ ] Test all options combinations
- [ ] Verify nothing breaks accessibility
