# Live Event Framework

## Event Types
- **Seasonal**: Holiday, anniversary events
- **Limited-Time**: Weekend events, flash sales
- **Community**: Goals, milestones
- **Competitive**: Seasons, tournaments

## Event Planning Checklist
- [ ] Theme and narrative
- [ ] Rewards and progression
- [ ] Entry requirements
- [ ] Duration and timing
- [ ] Server capacity
- [ ] Fallback plans

## Content Calendar
```
Week 1: Season launch
Week 2-3: Regular content
Week 4: Mid-season event
Week 5-6: Regular content
Week 7: End-season event
Week 8: Season transition
```

## Health Metrics
- **DAU/MAU**: Daily/Monthly Active Users
- **Retention**: D1, D7, D30
- **Session Length**: Time per session
- **Sessions/Day**: Frequency
- **Revenue**: ARPU, ARPPU

## Incident Response
1. Detect (monitoring alerts)
2. Assess (severity, impact)
3. Communicate (status page, social)
4. Resolve (hotfix, rollback)
5. Post-mortem (learn, prevent)

## A/B Testing
- Test one variable at a time
- Significant sample size
- Run for full event cycle
- Measure key metrics
- Document learnings
