# Level Layout Patterns

## Hub-and-Spoke
Central area with branching paths. Good for non-linear exploration.
- Clear navigation hub
- Optional paths with rewards
- Return mechanics (shortcuts, fast travel)

## Linear
Guided progression through sequence. Good for narrative-driven content.
- Clear forward path
- Pacing control via gates
- Backtracking prevention

## Open-World
Large explorable space. Good for sandbox gameplay.
- Points of interest distribution
- Regional theming
- Traversal mechanics integration

## Arena
Enclosed combat space. Good for boss fights and challenges.
- Cover placement
- Enemy spawn points
- Environmental hazards

## Verticality Design
- Elevation changes for variety
- Visual landmarks from heights
- Jump/climb mechanics integration
- Vertical combat considerations

## Player Guidance Techniques
- Lighting direction
- Architecture framing
- Color contrast
- Audio cues
- Environmental hints
