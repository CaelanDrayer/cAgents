# Technical Specifications

## Metric Standards

### Player Metrics
- Player height: ~1.8m (180 units)
- Player width: ~0.6m (60 units)
- Eye height: ~1.6m (160 units)

### Movement Metrics
- Walk speed: ~3m/s
- Run speed: ~6m/s
- Jump height: ~1.2m
- Jump distance: ~3m (running)

### Space Standards
- Corridor width (tight): 2m minimum
- Corridor width (comfortable): 3-4m
- Combat arena: 20m+ diameter
- Cover spacing: 3-5m apart

## Blockout/Greybox Workflow

1. **Paper Design**: Sketch layout on paper
2. **Rough Blockout**: Basic geometry, no detail
3. **Playtest**: Test flow and pacing
4. **Refined Blockout**: Proper metrics, props
5. **Art Pass**: Handoff to environment art
6. **Polish**: Final adjustments

## Performance Considerations
- Level streaming boundaries
- Occlusion culling zones
- Draw distance planning
- Memory budget per area
