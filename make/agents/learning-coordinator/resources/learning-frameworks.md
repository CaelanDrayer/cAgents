# Learning Frameworks and Methodologies

Detailed reference for learning program design, skill assessment, and training delivery.

## Skill Assessment Framework

### Competency Matrix

Use a competency matrix to map current skills against required skills per role:

| Competency | Novice (1) | Developing (2) | Proficient (3) | Expert (4) | Master (5) |
|------------|-----------|-----------------|-----------------|------------|-------------|
| Definition | Needs guidance on basics | Can perform with supervision | Works independently | Teaches others | Innovates and leads |
| Evidence | Completed intro training | Handled 3+ tasks with support | Delivered 5+ tasks solo | Mentored 2+ people | Published or standardized |

### Gap Analysis Process

1. **Inventory current skills** - Survey team members using the competency matrix
2. **Define target state** - Map required competencies for each role and project
3. **Calculate gaps** - Subtract current level from target level per competency
4. **Prioritize gaps** - Rank by business impact and urgency
5. **Design interventions** - Match gap severity to learning method

### Gap Severity Classification

| Gap Size | Severity | Recommended Intervention | Timeline |
|----------|----------|--------------------------|----------|
| 1 level | Low | Self-paced learning, reading | 2-4 weeks |
| 2 levels | Medium | Structured course + practice | 1-3 months |
| 3 levels | High | Intensive training + mentoring | 3-6 months |
| 4 levels | Critical | Formal program + coaching + project rotation | 6-12 months |

## Learning Methodologies

### 70-20-10 Model

The foundational framework for blended learning design:

- **70% Experiential** - On-the-job tasks, stretch assignments, project work
- **20% Social** - Mentoring, coaching, peer learning, code review
- **10% Formal** - Courses, workshops, certifications, reading

### ADDIE Instructional Design

A systematic approach for creating training programs:

1. **Analyze** - Identify learning needs, audience, constraints
2. **Design** - Define objectives, assessment strategy, content outline
3. **Develop** - Create materials, exercises, evaluation instruments
4. **Implement** - Deliver training, facilitate sessions, support learners
5. **Evaluate** - Measure effectiveness, gather feedback, iterate

### Bloom's Taxonomy for Objectives

Write learning objectives at the appropriate cognitive level:

| Level | Verbs | Example Objective |
|-------|-------|-------------------|
| Remember | List, define, recall | List the 5 SOLID principles |
| Understand | Explain, describe, summarize | Explain why dependency injection improves testability |
| Apply | Implement, use, demonstrate | Implement a REST endpoint using the team's patterns |
| Analyze | Compare, debug, differentiate | Debug a race condition in concurrent code |
| Evaluate | Assess, critique, justify | Evaluate trade-offs between SQL and NoSQL for a use case |
| Create | Design, architect, build | Design a scalable microservice architecture |

## Training Program Templates

### Technical Skill Ramp-Up (4 weeks)

```
Week 1: Foundations
  - Environment setup and tooling
  - Architecture overview and key patterns
  - Guided codebase walkthrough
  - First small task with pair programming

Week 2: Guided Practice
  - Complete 3 well-scoped tasks with mentor review
  - Attend 2 design/architecture discussions
  - Study domain-specific documentation
  - Shadow a senior team member for 1 day

Week 3: Supervised Independence
  - Take ownership of a medium feature
  - Participate in code review (both giving and receiving)
  - Present a brief knowledge share to the team
  - Identify one process improvement

Week 4: Assessment and Planning
  - Complete assessment tasks independently
  - Receive feedback from mentor and peers
  - Co-create 90-day development plan
  - Celebrate progress and set next milestones
```

## Evaluation Methods

### Kirkpatrick's Four Levels

Measure training effectiveness at increasing depth:

| Level | Measures | Method | When |
|-------|----------|--------|------|
| 1: Reaction | Satisfaction, relevance | Survey, NPS | Immediately after |
| 2: Learning | Knowledge gained, skills acquired | Quiz, practical test | End of training |
| 3: Behavior | On-the-job application | Manager observation, metrics | 30-90 days after |
| 4: Results | Business impact | KPI tracking, ROI analysis | 3-6 months after |

### Training ROI Calculation

```
ROI = ((Benefits - Costs) / Costs) x 100

Benefits include:
  - Reduced time-to-competency
  - Fewer errors or rework
  - Increased throughput
  - Reduced turnover

Costs include:
  - Facilitator/mentor time
  - Materials and tools
  - Participant time away from work
  - Administrative overhead
```

## Best Practices

- Set measurable learning objectives before designing content
- Mix delivery methods to accommodate different learning styles
- Build in spaced repetition for long-term retention
- Require practical application within 48 hours of learning
- Collect both qualitative and quantitative feedback
- Review and update programs quarterly based on outcomes
- Align all training to business goals and team OKRs
