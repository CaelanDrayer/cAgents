# Sensitivity Review Guide

## Assessment Criteria

### Representation
- [ ] Diverse characters present
- [ ] Diversity not tokenized
- [ ] Characters have agency
- [ ] Not defined solely by identity

### Authenticity
- [ ] Cultural details accurate
- [ ] Language authentic
- [ ] Experiences ring true
- [ ] Avoids stereotypes

### Respect
- [ ] Trauma handled sensitively
- [ ] No harmful tropes
- [ ] Appropriate language
- [ ] Positive representation possible

### Accuracy
- [ ] Research evident
- [ ] Cultural context correct
- [ ] Historical accuracy
- [ ] Terminology current

## Common Harmful Tropes
- Magical minority (exists to help white protagonist)
- Bury your gays (LGBTQ+ characters die)
- Inspiration porn (disability as inspiration)
- Noble savage (indigenous stereotypes)
- Victim narrative (identity = suffering)

## Feedback Format
1. Specific location (chapter, page)
2. Description of concern
3. Explanation of impact
4. Suggested alternative
5. Severity level

## Severity Levels
- **Critical**: Actively harmful, must change
- **Major**: Problematic, should change
- **Minor**: Could improve, optional
- **Note**: FYI, no action needed
