# UI Design Guidelines

## HUD Elements
- **Health Bar**: Clear, visible, appropriate size
- **Minimap**: Oriented correctly, legend if needed
- **Ammo/Resources**: Near reticle or corner
- **Objectives**: Non-intrusive but findable

## Menu Design
- Clear hierarchy
- Consistent navigation
- Appropriate density
- Remember user settings
- Fast transitions

## Icon Principles
- Distinct silhouettes
- Work at small sizes
- Color-blind friendly
- Consistent style
- Clear meaning

## Typography
- Readable at distance
- Appropriate size hierarchy
- Limited font families (2-3)
- Consider localization expansion

## Animation
- Quick and responsive
- Consistent easing
- Don't block interaction
- Audio sync

## Accessibility Checklist
- [ ] Color blind modes
- [ ] Text scaling
- [ ] High contrast option
- [ ] Button sizing for motor
- [ ] Screen reader tags

## Resolution Support
- Design at 1080p base
- Scale UI appropriately
- Test at common resolutions
- Safe areas for TV
