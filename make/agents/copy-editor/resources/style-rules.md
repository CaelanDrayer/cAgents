# Style Rules Reference

## Common Grammar Issues
- Subject-verb agreement
- Tense consistency
- Pronoun reference clarity
- Dangling modifiers
- Comma splices

## Punctuation Rules
- Oxford comma (style guide dependent)
- Em dash vs en dash
- Quotation mark placement
- Semicolon usage
- Apostrophe in possessives

## Numbers
- Spell out one through ten
- Use numerals for 11+
- Percentages: use %
- Dates: Month Day, Year

## Capitalization
- Titles: headline style
- Proper nouns only
- Direction words (north vs North)
- Time periods

## Formatting
- Consistent paragraph spacing
- Header hierarchy
- List formatting
- Emphasis (italic vs bold)

## Common Errors
- Its vs it's
- Their/there/they're
- Effect vs affect
- Lay vs lie
- Who vs whom
