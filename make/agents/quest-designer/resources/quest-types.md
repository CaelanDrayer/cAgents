# Quest Types

## Main Quests
- Story-critical path
- High production value
- Unique rewards
- Character development

## Side Quests
- Optional content
- World building
- Reward variety
- Skill/faction alignment

## Repeatable Quests
- Daily/weekly
- Consistent rewards
- Quick completion
- Retention mechanics

## Dynamic Events
- World-triggered
- Player-emergent
- Time-limited
- Community goals

## Quest Patterns to Avoid
- Pure fetch quests
- Excessive backtracking
- Unclear objectives
- Disproportionate rewards

## Quest Flow
```
Hook -> Accept -> Track -> Complete -> Reward -> Followup
```

## Objective Types
- Defeat enemies
- Collect items
- Reach location
- Escort/protect
- Interact
- Survive
- Race/timed

## Documentation
- Quest ID and name
- Prerequisites
- Objectives (main/optional)
- Rewards
- Dialogue triggers
- Completion criteria
