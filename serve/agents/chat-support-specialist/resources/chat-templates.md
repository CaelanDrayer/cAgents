# Chat Support Templates

## Opening Messages

**Standard Opening**:
```
Hi [Name]! Thanks for reaching out. I'm [Your Name] and I'm here to help.
I see you're asking about [topic]. Let me look into this for you.
```

**If Delayed**:
```
Hi [Name]! Thanks for your patience. I'm ready to help you with [issue].
```

## During Chat

**Keep Informed**:
"Looking into your account now..."

**Ask Clearly**:
"Just to confirm, you're seeing [X] when you try [Y]?"

**Step-by-Step**:
```
Perfect! Here's what we'll do:
1. Click [X] in the top right
2. Select [Y] from dropdown
3. Click [Z] to save
Let me know once you've done that!
```

**Show Empathy**:
"I understand how frustrating that must be."

## Closing

```
Great! Is there anything else I can help with today?

Perfect! If you need anything else, just start a new chat. Thanks!
```

## Concurrent Chat Priorities

| Priority | Example | Time |
|----------|---------|------|
| High | Critical bug | 5 min |
| Medium | Sales question | 3 min |
| Low | Simple how-to | 1-2 min |
| Low | Feedback/praise | 1 min |

## Common Scenarios

### Password Reset
```
Agent: I can help with that. What's the email on your account?
Customer: user@example.com
Agent: Perfect! Reset link sent. Check inbox in 2-3 minutes. Link good for 1 hour.
```

### Complex Technical
```
Agent: This needs deeper investigation. I'm creating a support ticket so our
       technical team can look into it properly. Ticket #12345.
       They'll email updates within 4 hours.
```

### Angry Customer
```
Agent: I'm really sorry you're experiencing this. I can hear how frustrated
       you are. Let me help get this working right now.
       Can you tell me exactly what you're trying to do?
```

## Keyboard Shortcuts

- Ctrl+K: Search KB
- Ctrl+Shift+S: Insert canned response
- Ctrl+T: Transfer chat
- Ctrl+E: Escalate to ticket
- Ctrl+1-4: Switch between chats
