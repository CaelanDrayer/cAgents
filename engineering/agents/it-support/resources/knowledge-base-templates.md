# Knowledge Base Templates

Standardized templates for IT support documentation.

## Article Template

```markdown
# [Issue Title - Searchable Keywords]

## Summary
Brief one-line description of the issue and solution.

## Symptoms
- Symptom 1: What the user sees/experiences
- Symptom 2: Error messages displayed
- Symptom 3: Unexpected behavior

## Affected Systems/Users
- Operating systems: Windows 10/11, macOS, Linux
- Applications: [List affected applications]
- User groups: [All users, specific department, etc.]

## Root Cause
Explanation of why this issue occurs. Technical details for support staff.

## Resolution Steps

### Quick Fix (User Self-Service)
1. Step 1 with clear instructions
2. Step 2 with screenshots if helpful
3. Verify the fix worked

### Standard Resolution (IT Support)
1. Detailed step 1
2. Detailed step 2
3. Verification steps
4. Cleanup if needed

### Advanced Resolution (Requires Escalation)
When to escalate and to whom.

## Prevention
How users can avoid this issue in the future.

## Related Articles
- [Link to related KB article 1]
- [Link to related KB article 2]

## Metadata
- Created: YYYY-MM-DD
- Updated: YYYY-MM-DD
- Author: [Name]
- Category: [Network/Software/Hardware/Access/Email]
- Tags: [tag1, tag2, tag3]
```

## How-To Guide Template

```markdown
# How To: [Task Description]

## Overview
Brief description of what this guide helps users accomplish.

## Prerequisites
- Requirement 1 (e.g., admin rights, specific software)
- Requirement 2 (e.g., network connection)
- Time estimate: X minutes

## Step-by-Step Instructions

### Step 1: [Action]
Description of what to do.

![Screenshot description](path/to/screenshot.png)

### Step 2: [Action]
Description of what to do.

> **Note:** Important information the user should know.

### Step 3: [Action]
Description of what to do.

> **Warning:** Potential issue to be aware of.

## Verification
How to confirm the task was completed successfully.

## Troubleshooting
Common issues and solutions:

| Problem | Solution |
|---------|----------|
| Issue 1 | Fix 1 |
| Issue 2 | Fix 2 |

## FAQ
**Q: Common question 1?**
A: Answer to question 1.

**Q: Common question 2?**
A: Answer to question 2.

## Need More Help?
Contact IT Support: [contact information]
```

```markdown
## Description
[Detailed description of the incident]

## Impact
- Users affected: [Number/Group]
- Systems affected: [List]
- Business impact: [Description]

## Timeline
| Time (UTC) | Event |
|------------|-------|

[Steps taken to resolve the incident]

## Follow-Up Actions
- [ ] Action item 1 - Owner - Due date
- [ ] Action item 2 - Owner - Due date

## Lessons Learned
[What we learned and how we'll prevent recurrence]
```

## Categories

Organize KB articles into these categories:

### By Topic
- **Network**: VPN, Wi-Fi, connectivity
- **Software**: Applications, browsers, OS
- **Hardware**: Computers, peripherals, printers
- **Access**: Accounts, permissions, passwords
- **Email**: Setup, troubleshooting, best practices
- **Security**: Policies, awareness, reporting

### By Type
- **Troubleshooting**: Problem → Solution
- **How-To**: Task instructions
- **FAQ**: Common questions
- **Policy**: Rules and procedures
- **Training**: Learning materials

### By Audience
- **End Users**: Self-service guides
- **IT Support**: Technical procedures
- **Managers**: Approval workflows
- **Developers**: Dev environment setup
